# 企業向けアートワークショップ Webサイト

アーティスト Tadaomi Kawasaki による、企業課題解決のための出張型アートワークショップのランディングページです。

## 🎯 プロジェクト概要

BtoB向けの企業研修サービスとして、アート思考を活用したワークショップを提供するためのWebサイトです。
信頼感・清潔感・高級感を重視したデザインで、企業の意思決定者に訴求します。

## ✨ 主な特徴

- **BtoB向けデザイン**: 企業研修サービスとしての信頼感を重視
- **明確な課題提示**: 企業が抱える組織課題を具体的に提示
- **ソリューション重視**: アートを通じた課題解決の価値を明確化
- **導入しやすい設計**: 料金プラン、導入フロー、実績を明示
- **複数のCTA**: 無料相談、オンライン説明会など、段階的なアプローチ
- **レスポンシブ対応**: PC・タブレット・スマートフォンに完全対応

## 🚀 使い方

### ローカル環境での起動

```bash
# ディレクトリに移動
cd /home/user/webapp

# シンプルなHTTPサーバーを起動（Python）
python3 -m http.server 8000

# または Node.js を使用
npx http-server -p 8000
```

ブラウザで `http://localhost:8000` にアクセスしてください。

## 📱 レスポンシブ対応

- **デスクトップ**: 1200px以上
- **タブレット**: 768px〜1024px
- **スマートフォン**: 480px〜768px

## 🔧 カスタマイズ方法

### 色の変更
`style.css` の `:root` セクションで CSS変数を編集してください。

```css
:root {
    --primary-color: #2C3E50;
    --accent-color: #3498DB;
    /* その他の変数 */
}
```

### コンテンツの編集
`index.html` の各セクションを直接編集してください。

### フォーム送信先の設定
`script.js` の `contactForm.addEventListener('submit', ...)` 部分で、
実際のバックエンドAPIやメール送信サービスと連携してください。

## 📊 アナリティクス設定

Google Analytics などのトラッキングコードを追加する場合は、
`index.html` の `</head>` タグ直前に挿入してください。
